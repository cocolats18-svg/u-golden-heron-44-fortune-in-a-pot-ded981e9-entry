One kind, funny fortune for the houseplant on the windowsill: this week the morning sun will find its best leaf, and its keeper will stop just to admire it.

## Run it

```sh
node main.ts
```

`main.ts` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Node 22 standard library only; the output is byte-identical on every run.
